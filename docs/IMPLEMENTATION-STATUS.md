# WODSiege Android 파일럿 구현·검증 상태

기준일: 2026-09-06. 기준 기획: `PLAN-2026-09-06-wodsiege-product-concept.md`. 실행 패키지: `to-do-prompts/wodsiege-android-pilot/`. 정책 버전: `pilot-v1` **개발용, 운영 미승인**.

후속 업데이트: [기기·운영·복구·배포 준비 현황](READINESS-STATUS.md). 아래 표는 초기 앱 구현 검증 기록이며 후속 도구·서버 설정 강화·최신 테스트 수는 연결 문서에서 구분한다. 실제 기기/운영 승인/공개 배포가 완료되었다는 의미는 아니다.

## 산출물

- 사용자 지정 지시서: `intent-docs/INTENT-2026-09-06-wodsiege-android-pilot.md`. 목표·방향·내용·완료 기준 및 D/W 추적표. `intent-docs/` 전체 Git 제외 확인.
- `make-prompts`로 main과 4개 step 생성, `exec-prompts`로 기반→API→UI→Android/통합 검증 실행.
- React/TypeScript 앱, Capacitor Android 프로젝트, Node/SQLite API, 테스트 및 로컬 실행 문서.
- APK: `android/app/build/outputs/apk/debug/app-debug.apk`. 개발 서명, `app.wodsiege.pilot` / 0.1.0 / min API24 / target API36. 실제 휴대전화 연결 시 별도 PC API 필요.
- `frontend-design`을 적용해 기존 소개 보고서의 남색·주황·라임과 경기판 형태를 이어갔다. 좁은 화면은 하단 탐색과 단일 흐름, 펼친 화면은 탐색 레일과 목록/상세 두 영역이다. 폰트와 라이선스 고지를 번들에 포함한다.

## 구현 선택과 공개 전 남은 작업

현재는 개발자가 실행 가능한 파일럿이다. 실제 서비스 공개/스토어 출시 완료로 취급하지 않는다.

- SQLite는 단일 aggregate JSON을 트랜잭션으로 갱신한다. 소규모 파일럿 일관성을 우선했으며 대규모 조회·동시 접속·장기 운영을 위한 정규화/인덱싱/비동기 비밀번호 처리/마이그레이션·백업 설계가 필요하다.
- 위치는 클라이언트가 제공하는 값이다. 실제 사용자·현장 참여·운영권을 완전히 증명하지 않는다. 동일 폰 다중 계정/위치 위조 대책과 별도 운영 검토를 확정해야 한다.
- 영상은 앱 사용자에게 공개되는 홍보 자료가 아니며 권한 있는 검증용 파일이다. 원시 위치·영상·계정의 보관/삭제/동의·미성년 정책과 저장량 상한/운영 비용을 확정해야 한다.
- GPS/채점/팀/Elo/보상 수치를 승인받아 `pilot-v1` 다음 운영 정책을 정의해야 한다. 현재 D-01~D-13의 미정값을 승인된 정책으로 바꾸지 않았다.
- Fold7 USB 인수는 [ANDROID-TESTING.md](ANDROID-TESTING.md)의 체크리스트대로 수행한다. ‘폴더7’은 Galaxy Z Fold7 가정이다.
- 앱은 로컬 API 연결이 필요하다. 서버 배포·HTTPS·스토어 서명·공개·실제 참가자 초대·운영자 연락은 실행하지 않았다.

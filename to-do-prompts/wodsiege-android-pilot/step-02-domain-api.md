# Step 02 — 도메인·영속 API

## 목표와 기준

main 기준으로 Step 01 결과를 이어받아 W-01~W-09의 데이터 일관성과 권한을 구현한다. `docs/API.md`, `docs/PILOT-POLICY.md`, 원본 §4~10을 읽는다.

## 실행 지시

1. SQLite 영속 저장, 비밀번호 해시, 만료 세션, 일반 가입과 운영자 부트스트랩을 작성한다.
2. Box/가입 승인/3명 위치 확인/운영 승인과 WOD 버전 스냅샷을 구현한다.
3. 도전·수락·양측 명단 합의·잠금·시작·제출·검토·분쟁·확정·취소/무효/정정을 구현한다.
4. 비공개 실제 파일 업로드, 재시도, 권한 검사, 맹검, 수동 카운팅과 영상 시점 메모를 구현한다.
5. 점수 엔진, 부문별 Elo, 순위, 중복 안전 원장, 프로필 꾸미기·회수, 알림·운영 지표를 연결한다.
6. 임시 디렉터리 DB/업로드를 이용해 단위 및 API 통합 테스트를 수행한다.

## 제약과 산출물

서버가 역할·상태·값을 검증한다. 정책은 개발용이다. 외부 메시지·공개 영상·자기 분쟁 판정은 제외. 소유 영역 `server/`, `tests/server.test.mjs`, 필요한 도메인 테스트.

## 완료 기준

- 개인/3인 팀, For Time/AMRAP·동점·미완료 비교 검증.
- 2명/중복/GPS 오류, 권한 상승, 잠금 후 조작, 맹검·영상 접근 차단 검증.
- 제출 재시도/확정 재시도 중복 없음, 분쟁 보류, 정정 후 재계산·보상 회수 검증.
- DB 재연결 시 데이터 보존, 초과 소비 차단, 레이팅/포인트 분리.
- 모든 실패 또는 미지원 부분을 명시하고 수정 가능한 실패는 수정.

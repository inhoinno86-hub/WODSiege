# pilot-v1 개발 정책 (운영 미승인)

기획안 §13 D-01~D-13을 구현 가능하게 고정한 테스트용 정책이다. 실제 서비스 정책이 아니며 외부 공개 전 참가 Box·코치·운영자 검토가 필요하다.

- Android 우선, 한국어, Galaxy Z Fold7 가정. 한국 동/구 주소 필터. 전국/세계·시즌 제외.
- Box: 서로 다른 주 소속 계정 3명, 소속 동의, Box 중심 150m, 위치 정확도 ≤100m, 최근 10분, 미래 시각 거부. 누적 확인 방식이며 동시 방문 강제 없음. 위치 확인과 운영 권한 승인 분리. GPS는 본인/운영권 증명이 아니다.
- 개인 1인, 팀 3인 Open 개별 수행 합산, Rx/Scaled 분리. 성별/연령 정책은 확정하지 않는다.
- For Time: 완료자 우선→미완료 반복수 높은 순→완료시간 낮은 순. 팀은 완료 인원 많은 순→미완료자의 반복수 합 높은 순→완료자의 시간 합 낮은 순. AMRAP은 유효 반복수 합. 동일 지표는 무승부. 무효 동작은 reps에서 이미 제외한 횟수이며 중복 차감하지 않는다.
- 양측이 고정 WOD/일시/장소/명단 동의 후 잠금. 한 번의 지정 시도. 경기 후 24시간 제출, 48시간 검토. 양측 확인과 검토 기한 종료 후 확정. 시작 전만 관리자 취소 가능하며, 시작 후 미제출·수행 불가는 운영자 근거 판정으로 무효 처리한다. 미응답·분쟁도 운영자 근거 판정 대상이다. 개발 테스트는 주입 clock 사용으로 기한을 검증한다.
- 영상은 MP4/WebM, 100MB 상한, 등록 시 촬영 동의 확인. 비공개·양측 제출 전 상대 증거 맹검. 자동 판독 없음. 로컬 데이터 삭제/보관 정책은 공개 전 결정 필요. 개발 데이터에 실제 민감 영상을 사용하지 않는다.
- Elo 초기 1000/K24, format+level 별도. 같은 Box 쌍 하루 1회 레이팅·보상, 3경기 전 임시. 공동 순위. 확정 시 DB 원자적 반영, 정정 시 확정 순서대로 전체 재계산하여 후속 경기 일관성 유지.
- 정상 확정 경기 양 Box 20P. 프로필 꾸미기 30P 최초 1회. 포인트와 레이팅 별도. 취소/무효는 보상 없음. 정정 회수로 잔액이 음수가 되면 부채로 표시하고 추가 소비 차단.
- 앱 내 알림·운영 지표. OS push, 외부 메시지, 결제, 공개 배포, 실사용자 본인 확인은 미포함.

## 출시 전 남은 결정

후속 작업에서 [운영·개인정보 승인 준비서](PILOT-OPERATIONS.md)에 D-01~D-13의 담당 역할·완료 기준·요청/분쟁 처리 절차를 정리했다. 모두 검토 초안이며, 아래 항목이나 `pilot-v1` 수치를 승인된 운영 정책으로 변경하지 않는다.

운영권 증빙·실사용자 확인·팀 부문·WOD 운동 기준·GPS 기준·반복 상대 정책·상금 없는 포인트 보상/상한·미성년/촬영/보관/삭제·폐쇄/탈퇴·이의 기간·운영 인력·실제 서버/백업/비용·HTTPS/스토어 서명·테스트 Box·실기기 검증을 확정한다. 이를 완료했다고 표시하지 않는다.

검토 지적 2

비밀 파일 교체로 비밀번호가 바뀌지 않음

기존 운영자는 bootstrap 시 갱신되지 않아, 새 secret으로 재시작해도 기존 비밀번호가 유효했습니다. 검토자가 임시 DB의 로그인 결과로 확인했습니다.

  • 조치: 명시적 오프라인 비밀번호 변경 도구와 해당 운영자 세션 무효화 구현.

  • 확인: 새 로그인 성공, 이전 비밀번호·세션 거부, 일반 회원 세션 유지 회귀 검사.

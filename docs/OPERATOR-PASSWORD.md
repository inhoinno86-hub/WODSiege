# 운영자 비밀번호 오프라인 변경

기존 운영자 한 명의 비밀번호를 변경하고 그 운영자의 로그인 세션을 모두 무효화한다. 일반 회원의 비밀번호·세션·역할과 경기 데이터는 유지한다. 계정 생성이나 일반 회원의 운영자 승격은 하지 않는다. 서버 시작용 secret 파일만 교체하거나 서버를 재시작하는 것으로는 기존 비밀번호가 바뀌지 않는다.

## 준비

1. API와 데이터에 쓰는 모든 프로세스 및 자동 재시작을 중지한다. 변경과 검증이 끝날 때까지 실제 요청을 받지 않는다.
2. [백업 안내](BACKUP-RESTORE.md)에 따라 새 경로에 백업하고 `data:verify` 성공을 확인한다.
3. 저장소 밖의 접근 제한 경로에 운영자 이메일 파일과 새 비밀번호 파일을 준비한다. 비밀 값을 명령행·채팅·Git에 기록하지 않는다.

두 파일은 각각 한 줄이며 소유자만 읽거나 쓸 수 있어야 한다(예: `0600` 또는 `0400`). 그룹/다른 사용자 접근, 심볼릭 링크와 하드 링크를 거부한다. 명령을 실행하는 계정은 파일 읽기와 DB 쓰기 권한이 필요하다. 앞뒤 공백은 기존 로그인 API와 동일하게 제거하며, 제거 후 비밀번호 길이는 10~200자여야 한다. 비밀번호 중간의 공백은 유지한다.

## 미리 확인하고 실행

아래 경로는 예시다. `--data-dir`에는 실제 `wodsiege.sqlite`가 있는 호스트 디렉터리를 지정한다. 환경 변수에서 자동으로 대상을 선택하지 않는다.

```bash
# 기본 dry-run: 계정과 입력을 확인하고 무효화할 세션 수만 출력
npm run operator:rotate -- \
  --data-dir /srv/wodsiege/data \
  --email-file /etc/wodsiege/operator-email.txt \
  --password-file /etc/wodsiege/operator-password-next.txt

# 백업 검증과 모든 작성 프로세스의 중지를 확인한 뒤 실행
npm run operator:rotate -- \
  --data-dir /srv/wodsiege/data \
  --email-file /etc/wodsiege/operator-email.txt \
  --password-file /etc/wodsiege/operator-password-next.txt \
  --execute --server-stopped
```

성공은 종료 코드 0과 `dryRun: false`로 확인한다. 출력에는 무효화한 세션 수와 변경 시각만 포함하고 이메일·비밀번호·토큰은 포함하지 않는다. 실제 변경은 하나의 SQLite 트랜잭션에서 비밀번호 해시 갱신과 해당 운영자의 세션 제거를 함께 처리한다. 기본 dry-run은 계정을 변경하지 않는다. SQLite 읽기가 WAL 공유 메모리나 잠금 파일을 사용할 수 있으므로 파일 바이트 전체가 그대로임을 보장하지는 않는다.

`--server-stopped`는 운영자의 확인이며 실행 중인 서버를 자동으로 찾아 중지하거나 정지를 증명하는 기능이 아니다. 경로와 상위 디렉터리는 신뢰할 수 있는 운영자만 변경할 수 있어야 한다.

## 변경 후 확인과 복구

서버가 다음 기동에도 유효한 secret 파일을 읽도록 bootstrap 비밀 파일도 새 값으로 관리한다. 서버를 시작한 뒤 새 비밀번호 로그인 성공, 이전 비밀번호 로그인 실패, 이전 운영자 세션 거부를 확인한다. `/api/health` 성공만으로 변경 완료를 판정하지 않는다.

검증에 실패하면 외부 요청을 차단한 채 서버를 다시 중지하고 대상 계정·데이터 경로·파일 권한을 점검한다. 이전 백업을 복원하면 이전 비밀번호 해시도 돌아오므로, 유출 대응 중에는 복원본에 새 비밀번호 변경을 적용하고 확인한 후 사용한다. 기존 DB를 수동 편집하거나 백업으로 덮어쓰지 않는다.

현재 도구는 호스트 경로용이다. `deploy/`의 API 이미지에는 이 스크립트를 포함하지 않으며 Docker named volume용 실행·UID 권한·격리 복구 절차는 해당 환경에서 별도 리허설이 필요하다.

## 검증

`node --test tests/operator-password.test.mjs`는 임시 DB와 시험용 비밀 파일로 실제 HTTP 재로그인, 이전 비밀번호·세션 무효화, 일반 회원 세션 유지, dry-run, 일반 회원 승격 거부, 파일 권한과 앞뒤 공백 처리를 검증한다. 실제 운영자 계정 변경은 수행하지 않았다.

# Step 03 — 앱 경험·서버 연결

## 목표와 기준

main 기준 Step 01 계약으로 한국어 Android 우선 UI를 구현한다. 원본 §10, `reports/wodsiege-introduction.html`, API/정책을 확인한다.

## 실행 지시

1. 가입/로그인, 홈·도전 탐색, Box/가입/위치 확인, 경기 생성·상세·명단 합의를 구현한다.
2. 실제 영상 선택/업로드, 기록/카운팅 입력, 상대 검토·이의, 결과·원장을 구현한다.
3. 지역/부문 순위, 내 활동/포인트 소비, 운영자 확인·분쟁 화면, 앱 내 알림을 구현한다.
4. 서버 실패·연결 설정·권한 거부·빈 상태를 행동 가능한 한국어로 표시한다.
5. 좁은 화면 1열/펼친 화면 2열, 48px 터치 영역, safe area, 키보드·회전 대응. 입력 초안은 민감정보를 제외하고 유지한다.

## 제약·산출물

가짜 성공·클라이언트 권한 판정 금지. 운영 역할은 서버 계정으로만 접근한다. 개발 정책을 실제 승인으로 표시하지 않는다. 산출물 `src/` 및 앱 설정.

## 완료 기준

- TypeScript와 번들 빌드 성공.
- 실제 API로 주요 사용자 동작 가능, 잘못된 입력 안내와 재시도 가능.
- 좁은/넓은 화면에 수평 넘침 없이 탐색 가능, 입력 중 크기 변경 유지.
- Fold7 실기기 전용 검증은 04 체크리스트에 남긴다.

## 인계

04에서 서버와 함께 실행하여 E2E와 Android 빌드를 검증한다.
